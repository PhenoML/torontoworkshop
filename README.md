# torontoworkshop

Assets for the PhenoML workshop "Hidden in Plain Text", Toronto, 2026-11-12.

## Start here

[northstar-assets/README.md](northstar-assets/README.md): the clinical notes, PDFs, FHIR samples, fact sheet and patient panel for the demo and the build exercise, with the PhenoML docs page each step uses.

## PhenoML links

- [Console](https://console.pheno.ml): sign in, create client credentials.
- [Docs home](https://console.pheno.ml/docs)
- [Guides](https://console.pheno.ml/docs/guides/overview) relevant to this workshop:
  - Construe, code extraction and custom code systems: [API](https://console.pheno.ml/docs/api-reference/construe), [Bring your own terminology](https://console.pheno.ml/docs/guides/custom-codes), [Extract codes you can trust](https://console.pheno.ml/docs/guides/trustworthy-codes)
  - Lang2FHIR, text and documents to FHIR R4: [API](https://console.pheno.ml/docs/api-reference/lang2fhir), [From clinical text to a populated EHR](https://console.pheno.ml/docs/guides/text-to-ehr)
- [SDKs](https://console.pheno.ml/docs/sdks): TypeScript, Python, Java.
